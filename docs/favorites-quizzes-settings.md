# المفضلة + الاختبارات + الإعدادات

## ❤️ المفضلة
- حسابي ← المفضلة (`FavoritesRoute`)
- إضافة/إزالة عبر `FavoritesStore.instance.toggle(studentId, courseId)`
- إعادة ترتيب بالسحب داخل شاشة المفضلة (`ReorderableListView`)
- ⚠️ زر "إضافة للمفضلة" لم يُربط بعد داخل صفحة تفاصيل الدورة نفسها (الزر موجود في تصميم القالب لكنه غير مفعَّل) — يحتاج تعديلًا صغيرًا إضافيًا عند العمل على صفحة الدورة الكاملة.

## 📝 الاختبارات
**مالك**: من قائمة دورات مادة معيّنة، أيقونة 🧠 بجانب كل دورة → `OwnerQuizzesRoute` (إنشاء اختبار: عنوان، وقت، عدد محاولات) → `OwnerQuizQuestionsRoute` (إضافة أسئلة اختيار متعدد أو صح/خطأ، مع تحديد الإجابة الصحيحة).

**طالب**: من تبويب الحصص داخل صفحة الدورة، زر "اختبارات الدورة" → `StudentQuizListRoute` (يعرض عدد المحاولات المتبقية وآخر نتيجة) → `QuizTakingRoute` (مؤقّت تنازلي إن وُجد، إرسال، تصحيح تلقائي فوري، عرض النسبة + مراجعة كل سؤال بالألوان: أخضر=صحيح، أحمر=خطأ اخترته).

### بصراحة كاملة
- الأنواع المدعومة: **اختيار متعدد** (إجابة واحدة أو أكثر) و**صح/خطأ** فقط. الترتيب، التوصيل، المقالي، السحب والإفلات **غير منفَّذة** — تحتاج واجهات سحب/توصيل تفاعلية معقدة يصعب ضبطها يدويًا بثقة كاملة بدون مترجم Flutter للتحقق.
- نسبة النجاح ثابتة 60% لكل الاختبارات حاليًا (وليست قابلة للتخصيص لكل اختبار بعد).
- تبويب "اختبارات الدورة" يعتمد على `course.id` من الـ API الوهمي للقالب الأصلي، بينما الاختبارات التي ينشئها المالك مرتبطة بـ`course.id` من `OwnerContentRepository` — **هذان المعرّفان غير متطابقين حاليًا** لأن صفحة تفاصيل الدورة لم تُربط بعد بالكامل بمستودع المالك المحلي (موثّق أدناه كخطوة قادمة). لتجربة الميزة فعليًا الآن: افتح اختبارًا من نفس معرّف الدورة الذي أنشأه المالك عبر التنقل المباشر بالكود، أو انتظر ربط صفحة الدورة الكاملة.

## ⚙️ الإعدادات (المفعَّلة فعليًا الآن)
- **الوضع الليلي**: يعمل حيًا فورًا في كامل التطبيق (`AppSettingsController.themeMode`، محفوظ محليًا)
- **اللغة**: تبديل عربي/إنجليزي حي فورًا (`AppSettingsController.locale`) — لاحظ أن معظم النصوص المُدخَلة يدويًا في هذا التحديث (شاشات المالك، المحفظة، الأكواد...) مكتوبة بالعربية مباشرة (Hardcoded) وليست عبر نظام `S.current`، لذلك **لن تُترجم تلقائيًا** عند التبديل للإنجليزية بعد؛ فقط الشاشات الأصلية للقالب (تسجيل الدخول، الرئيسية...) تترجم فعليًا.
- **تسجيل الخروج**: يعمل فعليًا الآن (يمسح جلسة الطالب المحلية ويعيد للدخول)
- **سياسة الخصوصية / الشروط / حول التطبيق / التواصل معنا**: شاشات نصية حقيقية الآن، لكن بمحتوى نموذجي (Placeholder) — المالك يجب أن يستبدله بالنص القانوني الفعلي قبل الإطلاق للجمهور.
- **الأمان (Security)**: لا يزال بلا وظيفة — يحتاج خادمًا حقيقيًا (جلسات، JWT، بصمة الجهاز) كما هو موثّق سلفًا.
- **جودة الفيديو الافتراضية/التشغيل التلقائي/مسح الكاش**: غير منفَّذة بعد.
